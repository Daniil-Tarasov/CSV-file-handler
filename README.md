# Генератор отчётов макроэкономических данных

## Описание

Генератор отчётов макроэкономических данных - генератор отчётов из CSV файлов.

## Установка

Клонируйте репозиторий:

```
git clone git@github.com:Daniil-Tarasov/CSV-file-handler.git
```

## Использование

1. Для использования используйте команду ```python main.py --files example.csv --report average-gdp``` или ```python3 main.py --files example.csv --report average-gdp```, где "example.csv" - название исполняемого файла (файлов может быть несколько), а "average-gdp" - название типа отчёта (на данном этапе доступен только average-gdp)

## Расширяемость

Данный проект можно расширить другими типами отчётов. Для этого в файле report.py добавьте в переменную reports в функции generate_report новое ключ-значение в словарь, где ключ - тип/название отчёта, а значение - функция создающая отчёт.

## Тестирование

Для запуска тестов используйте команду ```pytest```. Для получения отчёта используйте команду ```pytest --cov=src --cov-report=html```.
